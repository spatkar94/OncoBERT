# Biomarker discovery

| Workflow | Purpose |
|---|---|
| `treatment_cluster_interaction/` | Cluster-by-ICI interaction, subgroup KM, multivariable Cox, and external NSCLC validation |
| `cross_cancer/` | MSK-IMPACT and external response generalizability |
| `leiden_robustness/` | phenotype robustness over 5 resolutions x 20 seeds |
| `attention_modules/` | final-layer gene-gene attention, spectral modules, pathway enrichment, mutation patterns, and integrated gradients |
| `normalized_laplacian/` | standalone eigengap selection figure |

These are retrospective observational analyses. Treatment-interaction results
should not be interpreted as randomized treatment effects.
